分级规则
方法

在检测框内提取病征区域，计算病征覆盖率：

R = 病征像素数 ÷ 叶片像素数

分级阈值
等级病征覆盖率颜色
轻度R ≤ 0.10蓝色
中度0.10 < R ≤ 0.30橙色
重度R > 0.30红色
阈值确定依据
  • 基于 457 张验证集样本的病征覆盖率分布直方图
  • 自然断点法找到数据分布的天然分界点
  • 参考植物病害调查中病斑面积占比的常用分级标准
分组策略
组别病害类型分级策略
A 组 病斑型（早疫病、晚疫病、斑枯病、细菌性斑点病、靶斑病） HSV 颜色分割，计算病征覆盖率
B 组 黄化型（花叶病毒、黄化曲叶病毒） 颜色分割不可靠，输出保守参考值
